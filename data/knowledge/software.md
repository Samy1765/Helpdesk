# Software

## Installing approved software
1. Open the Company Software Center from the Start menu (or Self Service on macOS).
2. Search for the application and choose Install; approved titles install without admin rights.
3. If the application is not listed, submit a software request with the business justification; licensed software requires manager approval.

## Application crashes or freezes
1. Save your work, close the application and reopen it.
2. Check for updates in the application's Help > Check for updates menu, or in Software Center.
3. Clear the application cache (the helpdesk agent can do this with your approval) and sign in again.
4. Restart your computer to release locked files.
5. If it still crashes, note the exact error message and time so IT can check the crash logs.

## License or activation errors
1. Sign out of the application (Account or Profile menu) and sign in again with your company account.
2. Make sure you are connected to the internet or VPN; license servers must be reachable at start-up.
3. If the error says no license is assigned, request a license seat in the self-service portal - IT cannot assign seats by chat.
