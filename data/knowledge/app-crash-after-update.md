# Business application crashes or shows an error after an update

A crash right after an application update is usually a damaged local cache or settings file. Clearing the cache keeps your data, because work files are stored on the server or OneDrive.

## Symptoms
- The application closes immediately after the splash screen.
- An error such as "The application was unable to start correctly" appears.
- The application worked yesterday and an update was installed overnight.

## Resolution
1. Restart the laptop to complete any update that was waiting for a restart.
2. Clear the application cache. The helpdesk agent can do this with your approval; you will be signed out of that application.
3. Open the Company Portal, find the application and choose "Reinstall" if it is offered.
4. Note the exact error text or take a screenshot and attach it to the ticket.
5. Check whether a colleague in the same team has the same problem with the same version.

## Escalation criteria
Escalate to Software Support when:
- The application still crashes after a cache clear and reinstall.
- Several users report the same error after the same update (Software Support can pause the update ring).
- The crash risks data loss in an open document or transaction.
