# Installing Software and Requesting New Applications

## Approved software (no request needed)
1. Open Software Center (Windows) or Self Service (macOS) from the Start menu or Applications folder.
2. Search for the application, select it and choose "Install".
3. Keep the laptop on and connected until the status shows "Installed". Large packages such as Office or design tools can take 20 minutes.
4. Restart if the installer asks you to.

## Installation fails in Software Center
1. Check free disk space; most packages need at least 10 GB free.
2. Restart the laptop and try again; a pending update often blocks new installations.
3. Connect to the office network or VPN, since some packages download from internal servers.
4. If it fails twice, raise a ticket with the error code shown in Software Center.

## Software that is not in the catalogue
1. Raise a software request with the application name, version, business reason and whether it needs a paid licence.
2. Your manager approves the cost; the Security Team reviews new vendors before anything is installed. Expect three to five working days.
3. Do not download and install software from websites yourself. Laptops block unapproved installers, and attempts are logged.

## Browser extensions
Only extensions in the company browser store can be installed. Request others the same way as new software.
