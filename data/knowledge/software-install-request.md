# Install approved software from the Company Portal

Employees do not have local administrator rights. Approved applications install themselves from the Company Portal, and anything else is requested there and reviewed by Software Support for licensing and security.

## Symptoms
- An installer asks for an administrator name and password.
- You need a tool that is not on the laptop, such as Power BI Desktop, Python or AutoCAD.
- A downloaded installer is blocked by "Your organisation has blocked this app".

## Resolution
1. Open the Company Portal app from the Start menu and search for the application.
2. If it is listed, choose Install; most applications finish in under ten minutes and do not need a restart.
3. If it is not listed, choose "Request an app", give the business reason and the version you need; your manager approves the request.
4. Do not download installers from the internet; they are blocked and the attempt is logged.
5. Paid software (AutoCAD, Adobe Acrobat Pro, MATLAB) also needs a cost-centre code in the request.

## Escalation criteria
Escalate to Software Support when:
- An installation from the Company Portal fails twice with an error.
- An approved request has not been installed after two working days.
- You need software urgently for a customer delivery; mention the deadline in the request.
