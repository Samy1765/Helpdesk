# Moving MFA to a New Phone

## Plan ahead (old phone still works)
1. Install the authenticator app on the new phone.
2. On your laptop, sign in to the "Security info" page and choose "Add sign-in method", then "Authenticator app".
3. Scan the QR code with the new phone and approve the test notification.
4. Set the new phone as the default sign-in method.
5. Delete the old phone from the list only after the new one works.
6. Wipe the old phone before handing it in or selling it.

## Old phone already lost, reset or broken
1. If you also registered a mobile number, choose "Sign in another way" and use a text message code to reach the Security info page, then add the new phone as above.
2. If you have no other method, you cannot fix this yourself. Raise a ticket; the Identity & Access Team verifies who you are on a video call and issues a temporary access pass valid for one hour.
3. A lost company phone is also a security incident. Report it as described in the lost device runbook.

## Common problems
- Codes rejected: set the phone's date and time to automatic.
- No notifications arrive: allow notifications for the authenticator app and turn off battery optimisation for it.
