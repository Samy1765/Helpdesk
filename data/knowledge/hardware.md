# Hardware

## Laptop will not power on or charge
1. Connect the original charger directly to a wall socket (not a power strip) and check the charging light.
2. Try a different charger of the same wattage if one is available.
3. Hold the power button for 20 seconds to reset the power controller, then press it once normally.
4. If the battery is swollen, the case is lifting, or you smell burning, stop using the laptop immediately and contact IT.

## External monitor, keyboard, mouse or dock not working
1. Unplug the docking station from power and from the laptop, wait 30 seconds and reconnect.
2. Try the monitor or device directly on the laptop without the dock to isolate the faulty part.
3. For wireless devices, replace the batteries and re-pair the device.

## Screen flickering or display problems
1. Update the display driver from Software Center.
2. Check the display cable and try a different port.
3. Physical damage such as cracks or pressure marks must be handled by hardware support - request a repair.

## Blue screen crashes
1. Note the stop code shown on the blue screen.
2. Install pending Windows updates and restart.
3. If the crashes repeat, IT will collect crash dumps - report the stop code and how often it happens.
